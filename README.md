# deezlinks releases

Installers and the update manifest for deezlinks. The source lives in a separate repository.

Download the newest `deezlinks_<version>_x64-setup.exe` from [Releases](../../releases/latest). An installed copy with update checks turned on (Preferences > Updates) reads `latest.json` from the newest release and offers the update; every installer is signed and the app verifies the signature before installing.
